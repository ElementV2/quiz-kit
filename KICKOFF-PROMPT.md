# Prompt de lancement (à coller dans Claude Code à la racine du projet)

```
On démarre le projet Quiz Builder. Tout le cadrage est dans le dépôt :
CLAUDE.md, docs/ (vision, architecture, modèle, moteur, protocole, fiabilité, rendu, studio, régie,
joueurs/scores, sécurité, stack, conventions, audit, roadmap, questions ouvertes) et docs/adr/.

1. Lis CLAUDE.md puis tous les fichiers de docs/ et docs/adr/. Ne code rien pour l'instant.
2. Rends-moi un compte rendu court :
   - ta compréhension de l'archi en 10 lignes,
   - les incohérences ou trous que tu vois entre les docs,
   - les points de docs/OPEN-QUESTIONS.md que tu peux vérifier tout de suite dans la doc officielle
     (vérifie-les, avec les liens), et ceux qui restent ouverts.
3. Propose le découpage de la Phase 0 en tâches de moins d'une demi-journée, dans l'ordre, avec pour
   chacune les tests qui prouveront qu'elle est finie.
4. Attends mon feu vert avant d'initialiser le monorepo.

Règles permanentes : ne jamais inventer une API, une option ou une version — vérifier dans la doc
officielle ou dans les types installés. Si ce n'est pas vérifiable, le dire.
```

Ensuite, pour chaque tâche : `/next-task` (ou `/next-task <intitulé de la case>`).
